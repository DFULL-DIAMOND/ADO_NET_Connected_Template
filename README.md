# Шаблон: ADO.NET Connected Mode (Присоединенный режим)

Этот репозиторий — базовый шаблон (boilerplate) для WinForms-приложений, работающих с базой данных MS SQL Server в **присоединенном режиме** с использованием `SqlDataReader`.

## 🏗 Архитектура
*   **UI (WinForms)**: `ClosedForm` (окно подключения) и `Form1` (главное окно).
*   **Data**: `ConnectionFactory` (строка подключения), `QueryDefinition` (описание запроса) и `QueryRunner` (выполнение через `SqlDataReader`).
*   **Queries**: `QueryRegistry` (словарь всех SQL-запросов приложения).
*   **Особенность**: Соединение с базой открывается в `ClosedForm` и передается в `Form1`. Оно остается открытым до явного закрытия пользователем.

## 🚀 Как начать новый проект на базе этого шаблона:
1. Нажмите **"Use this template"** на GitHub (или склонируйте репозиторий).
2. Откройте решение в Visual Studio.
3. В файле `Data/ConnectionFactory.cs` измените `InitialCatalog` на имя вашей базы данных.
4. В `Queries/QueryRegistry.cs` очистите старые запросы и добавьте свои.
5. В `Form1.cs` обновите пункты меню в `ComboBox`, чтобы они соответствовали вашим новым запросам.
6. Убедитесь, что в вашей базе данных есть таблицы, к которым вы обращаетесь.

## ⚠️ Важно помнить (Особенности режима):
*   Этот режим держит открытое соединение с БД (что расходует ресурсы сервера).
*   Чтение данных идет построчно, что идеально подходит для обработки огромных таблиц (миллионы строк).
*   `DataGridView` заполняется вручную построчно через методы `BeginResult` и `AppendRow` в `WinFormsDataPresenter`.
